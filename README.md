# まなびカードバトル v0.2.0

PhantomCardBattle v0.1.62をベースに、5教科（こくご・さんすう・りか・しゃかい・えいご）の学習カードゲームへ置き換えた開発版です。

## 主な実装
- 250枚の学習カード
- 16人＋大人モード16人のNPC
- ひらめきスキル9種
- 学び成長（スーパー→ハイパー→マスター）
- ひらめきのかけら / 5教科パワー / まなびポイント
- 50種類のコレクションボーナス
- 3枚販売ショップ / お買い物ランク1～5
- オンライン対戦・ランキングを維持
- Firebaseデータは `manabi_card_battle_v1/` 配下を使用しPCBと論理分離

## カード画像について
現時点ではカード名と教科アイコンを使った仮アートです。`cardArtHtml()`を差し替えるか、カード画像素材を追加すると本番アートへ移行できます。

## Firebase
`firebase-config.js` は元PCBの設定を引き継いでいます。Realtime Databaseのルールが `manabi_card_battle_v1` 配下への読み書きを許可していることを確認してください。
